# 固定模板参数

> 先用 `scripts/check_preset.py --template <解密后的参考时间线>` 验证；参数来自参考工程，不凭记忆。

## 1. 画布与速度

- 1080×1920（9:16 竖屏）
- 30fps（草稿不记录 fps 时按 30 处理）
- 视频/音频 1.2×；字幕时间按 1.2 重定时

## 2. 调色

- 素材名：`调色所有小项`
- resource_id：`7416258989467374091`
- value：**0.8**
- 每个视频片段都挂

## 3. 顶部模糊

- 素材名：`模糊`
- resource_id：`7399495140399746304`
- 类型：video_effect + 矩形蒙版
- 常见蒙版 A：高 **0.1507**，中心 Y **0.6262**（多数工程）
- 常见蒙版 B：高 **0.1459**，中心 Y **0.7025**（较新一套）
- 只盖上部，用来遮原素材烧录标题；不是全屏模糊
- 复制时保留 `effect_mask` 的 width/height/centerY；不要重新画全屏

## 4. 字幕

- 字体：`细体-思源黑体7号.otf`
- 字号：**12**
- 颜色：`#FFFFFF`
- 位置：y≈**-0.236**
- 阴影 alpha 0.9；描边 0.08
- 单行；`line_max_width` 1.0，`force_apply_line_max_width` true
- 长句上限 **11 字**；按词边界拆两条
- 句间 0 缝（上一条 end = 下一条 start），最多留 1.0s；靠 start 取整防 30fps 同帧叠字

## 5. 标题

- 字体：`仓耳丰黑.ttf`
- 颜色：`#FFFFFF`
- 两行：13 号 + 12 号
- 顶部：y≈0.7446 / 0.6231
- 全片持续；不要逐段重放

## 6. 轨道

- 视频
- 暗角/冲刺（可选语义特效）
- 模糊（全片，顶部蒙版）
- 标题 ×2
- 音频（原声 + 稀疏音效）
- 字幕（数组末尾；render_index 15000 / track_render_index 8）

## 7. 不要

- 不要加 BGM、转场、贴纸（除非用户明确要求）
- 不要加关键帧/缩放位移
- 不要把字幕放在模糊下面
- 不要用全屏模糊替代顶部蒙版

## 8. 版本差异

- 不同系列可能换字体/字号/蒙版（如新青年体、系统黑体）。
- 先以**当前参考工程**为准；`preset.json` 是默认值，不是永久真理。
