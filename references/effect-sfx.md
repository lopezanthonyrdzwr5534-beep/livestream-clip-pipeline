# 特效 / 音效语义

## 1. 总原则

- 音效是主要强调手段；视觉特效很克制。
- 音效密度：**0.3–1.2 个/分钟**，6 分钟约 3–5 个。
- 额外视觉特效：6 分钟 0–2 个；多数 0 个。
- 先判断这句话在干什么，再选一个最贴的；宁可不加。
- 不固定在某秒放水滴；位置由台词决定。

## 2. 映射

| 语义 | 音效 | 视觉特效 |
|---|---|---|
| 说破负面真相/负面结论 | 水滴声 | 暗角（强时） |
| 下结论/关键词落地 | 字幕音效-嘭 | 无 |
| 给建议/警告/劝退 | 系统警告（连续否定） | 聚光灯 |
| 冲突/连续否定/重复 | 砰，拳击声（可连打） | 气炸了（强时） |
| 社死/尴尬/自嘲 | 尴尬 / 尴尬逃跑效果音 | 满屏问号 / 荧幕噪点 |
| 换话题/列点/场景切换 | 书本翻页声 | 无 |
| 玩笑/溜了 | 搞笑配音（咚咚咚溜走） | 无 |
| 震惊/悲凉/恍然/算账 | 一次性长尾音效 | 大脑混乱 / 凄凉 / 惊讶 / 灵机一动 / 飞速计算 |
| 揭示/亮出观点/换话题 | 综艺亮了或提示音 | 无 |
| 恍然/想起来/“叫什么名字” | 咻，抛物弹簧音 | 无 |
| 吐槽/不满/“红温” | 无 | 红温大头 |
| 连续列点/连续负面理由（吐槽） | 噗，短放屁声（可连打 4–6 次） | 无 |
| 普通陈述/过渡 | 不加 | 不加 |

## 2.1 2026-10-26 从用户手动精剪观察到的偏好

用户在当前 03–08 的手动版本里，保留/新增了这些选择：

- **水滴声/暗角**：仍用于“说破负面真相”，例如“我不太想让他去这种公司”“AI 是把这岗位彻底消失了”“游戏和影视是所有设计行业里边加班最多最狠的”。
- **冲刺**：用于薪资/性价比句，例如“基本上都是在 10,000 起”“算是加班比较少的了”“算是工资比较高的了”。
- **综艺亮了或提示音**：用于亮出判断/切换话题，例如“工资高低取决于……”。
- **咻，抛物弹簧音**：用于恍然/想起来，例如“我知道叫什么名字”。
- **红温大头**：用于吐槽/不满，例如“然后还问我能不能报我的班”。
- **噗，短放屁声**：用于连续负面理由的吐槽式列点，08 里连打 6 次：
  “因为你学了一个大类 / 哪个都接触了一点点 / 没有一项专业技能 / 没有一项岗位技能 / 老师教的知识滞后 / 老师能力也没那么强 / 教不出来什么有用的东西”。
  这种是有意的喜剧节奏，不是常规密度。

密度修正：

- 常规仍 **0.3–1.2 个/分钟**；
- 连续列点/玩笑可以局部连打，单段可到 2–4 个/分钟，但全片不要长期维持；
- 视觉特效仍克制，一半以上片子只有 0–2 个（暗角/冲刺/红温大头）。

素材注意：模板只带了水滴声、暗角、冲刺、模糊；综艺提示音、咻、红温大头、噗等必须从用户当前工程/参考时间线**按名称克隆 material**，不能只写名字。

## 4. 落点

- 音效起点对到关键词/句首，常与切点重合。
- 重复句可连打（“逃避现实”×3 → 拳击×3；“别去…”×4 → 系统警告×4）。
- 段落切换用翻页/综艺开始；负面真相用水滴/暗角；建议用聚光灯。
- 不要每段都加；普通陈述留白。

## 5. 不要

- 不要加 BGM 铺底（大多数样本没有）。
- 不要加转场/贴纸（除非用户明确要求）。
- 不要把固定“调色/模糊”当额外特效统计。


## 素材从哪来：fx_library（2026-10-26 起可克隆）

固定模板只带 水滴声 / 暗角 / 冲刺 / 模糊。其余音效与特效**不是不能加**，而是必须先建库：

```bash
python scripts/build_fx_library.py --plain <用户时间线解密目录> --out assets/fx_library.json
python scripts/build_draft.py --template <参考> --edl <edl.json> --out <草稿>   # 自动读同目录 assets/fx_library.json
```

库里每个名字保存：完整 material（已剥 `request_id`、`algorithm_artifact_path`）、段模板、
以及 5 个 extra ref 子素材（`speeds / placeholder_infos / beats / sound_channel_mappings / vocal_separations`），
克隆时全部重新分配 id，所以一条音效连打 6 次是 6 份独立 material（和用户手加的一样）。

已验证过（无头导出 + 同 EDL 去掉事件的对照片逐窗比差异）：
`综艺亮了或提示音`、`咻，抛物弹簧音`、`噗，短放屁声`（连打 4 次全部有声）、`红温大头`（窗内 97% 像素差异、窗外 0%）。

约束：
- `fx_library.json` 里的 `path` 是本机剪映 Cache 绝对路径，换机器/清缓存后要重跑建库；
- 名字必须和素材库里的 `name` 一字不差（含中文逗号），写错会 `WARN ... skipped` 而不是瞎替换；
- 脸谱类（红温大头）克隆后仍要剪映目视，它依赖人脸检测；
- 每次用户手工往工程里加了新音效，就重跑一次建库命令，别把名字硬写进 EDL。
