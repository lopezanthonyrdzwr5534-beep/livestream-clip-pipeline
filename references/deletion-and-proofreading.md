# 删句与字幕校对

## 1. 删句：整句删，不逐字删

目标删除率：**5–15%**（多数中位约 7%）。

优先删：

| 类型 | 例子（通用） |
|---|---|
| 语气词/无信息 | “啊”“嗯”“哦”“对”“好吧” |
| 短插话/半句 | “很很难”“就就时间”“还是大三” |
| 口吃/自我修正 | “他他他好几”“就是我我我” |
| 重复/自我引用 | “我之前讲过”“这个事我昨天讲过”“还有一个…”（紧接重复） |
| 广告/引流 | “把关注点一点”“有什么课程” |
| 内容旁支 | 不推进主线的例子、废弃念头、跑题问答 |

保留：

- 主线判断/结论；
- 支撑主线的关键例子；
- 数字/薪资/offer；
- 有记忆点的情绪句；
- 观众需要的前因后果。

不要把未选中的几小时原片算成删除；只统计这条成片实际用到的源窗口。

## 2. 字幕：只改错字/术语/代词

允许：

- ASR 错词/术语：`树莓→数媒`、`d边→地编`、`d→地`、`w→vib`；
- 代词按语境：女学生“她”、物/城市“它”、人“他”；
- 金额：`12,000`、`168,000`、`3,000`。

禁止：

- 改写/润色；
- 删口癖（保留句内的啊/呃）；
- 改词序（`一发我`不要改成`发给我`）；
- 把“所以”改成“那”、“得”改成“的”；
- 把“其他”改成“其她”。

## 3. 单行与拆条

- 每条只显示一行；不能靠缩小字号/加宽来塞。
- 长句在**词边界**拆两条；不要切开“子公司/暑假/也是/168,000”。
- 两条拼起来必须等于原句（归一化后逐字一致）。
- 上限 **11 字**（2026-11-18 用户改；此前是 12 字），单行；以实际字体为准。
- **上一条结尾 = 下一条开头（0 缝）**；0 重叠；真实长停顿最多留 1.0s 缝；段首/段尾铺到段边界。

## 4. 校对清单

```
index | 原句 | 新句 | 类型（术语/代词/金额/拆条） | 依据
```

让用户能逐条审；不要静默润色。
